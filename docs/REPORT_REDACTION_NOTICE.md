# Original Report Redaction Notice

The original team report is **not** committed verbatim to this public repository.

## Reason

The original material contains environment-specific security information, including historical credentials/keys and infrastructure details that should not be republished as part of a public portfolio.

## Public reconstruction policy

This repository keeps:

- architecture concepts;
- technology choices;
- evidence classification;
- test methodology;
- sanitized deployment examples;
- lessons learned.

It removes or abstracts:

- passwords;
- private keys;
- setup/enrollment keys;
- tokens/sessions;
- historical infrastructure addresses where unnecessary;
- screenshots that expose sensitive values;
- account-specific cloud details.

## Important note

Redaction is not a substitute for credential rotation. Any credential from an old report that could still be active should be revoked or rotated.
