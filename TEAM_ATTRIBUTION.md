# Team Attribution

## Project nature

This was a **collaborative university team project**. The portfolio owner did not work alone, and this repository does not present the original system as a solo implementation.

## Portfolio owner role

**Syifani Adillah Salsabila — Group Lead (Ketua Kelompok) & Technical Contributor**

As Group Lead, responsibilities included coordinating the team's technical delivery, aligning implementation and validation work, reviewing progress/integration, and helping drive the final project output. The role was not purely managerial: it also involved hands-on participation in the technical work and project verification.

## Attribution policy

This repository follows three rules:

1. **Team-level implementation is described as team work.**
2. **Leadership is stated explicitly where it is known.**
3. **Specific individual authorship is not invented when the surviving evidence does not identify who performed a particular command, screenshot, or configuration change.**

This is important because the purpose of the repository is to make the portfolio more verifiable, not to convert collaborative work into a false solo-authorship story.

## Portfolio wording

Recommended wording:

> Led a collaborative network-security project as Group Lead while contributing hands-on to the design, implementation, and validation of a NetBird/WireGuard secure overlay and Dockerized Nextcloud collaboration environment.

Avoid wording such as:

> Solely built the complete infrastructure and every security component.

The second statement is not the intended attribution model for this repository.
