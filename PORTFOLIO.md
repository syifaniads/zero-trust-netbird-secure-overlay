## Interview talking points

A strong interview walkthrough is:

1. Start with the problem: distributed SME nodes need private collaboration without broad public exposure.
2. Explain the overlay: NetBird provides managed WireGuard connectivity between enrolled peers.
3. Explain the trust boundary: authenticated overlay membership does not automatically imply access to every peer/service.
4. Explain policy: NetBird controls network reachability; Nextcloud controls file/user permissions.
5. Explain verification: test both permitted and restricted paths, not only successful connections.
6. Explain engineering judgment: the final report contains some inconsistent Ryu/SDN/VNF references, so this portfolio deliberately avoids claiming them without matching evidence.
7. Explain leadership: as Group Lead, coordinate scope, integration, validation, and delivery while sharing technical work with the team.
