# Sanitized Examples

Files in this directory are **illustrative portfolio examples**, not verbatim exports from the historical project environment.

They exist to show the implementation pattern without leaking credentials, addresses, setup keys, account identifiers, or other sensitive deployment data.

- `netbird-policy.example.md` — conceptual least-privilege policy model.
- `docker-compose.nextcloud.example.yml` — generic Nextcloud + database Compose example.

Do not infer that placeholder values match the original environment.
